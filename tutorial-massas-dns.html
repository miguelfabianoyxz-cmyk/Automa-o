Tutorial v3.0 ⏱ ~5 min

Como usar
Massas & DNS

Cole dados de teste (CPF, Nome, Conta…) e URLs de ambiente (HML, PROD, DEV…), escolha um engine de parse e gere tabelas interativas com produto cartesiano automático. Tudo roda 100% no browser.

12 engines de parse Filtro em tempo real CSV · TSV · JSON 100% offline Dark mode

Pronto para começar? Abra a ferramenta e use os dados de exemplo para uma demonstração rápida.

Abrir a ferramenta
1

Visão geralO que a ferramenta faz e como está organizada

A ferramenta recebe dois inputs — Massa de Dados (registros CSV/Excel) e DNS / Ambientes (lista de URLs) — e gera automaticamente três saídas interativas:

Aba Massas
Tabela com todos os registros parseados do CSV, com cabeçalho detectado automaticamente e destaques de duplicatas.
Aba DNS
Tabela com ambiente (badge colorido) e URL de cada linha, com inferência automática de ambiente pelo nome da URL.
Visão Combinada
Produto cartesiano: cada registro de massa combinado com cada URL. Ideal para mapear todos os cenários de teste.
Stats Bar
Contadores: registros, DNS, combinações, ambientes únicos, colunas detectadas e engine ativo.
ℹ️
Como funciona o produto cartesiano: se você tiver 3 registros de massa e 4 URLs de DNS, a aba "Visão Combinada" terá 3 × 4 = 12 linhas — cada pessoa testada em cada ambiente.
2

FuncionalidadesTudo que você pode fazer na ferramenta

Filtro em tempo real
Busca instantânea em qualquer coluna com destaque dos termos encontrados e debounce de 160 ms.
Pré-visualização ao vivo
Veja como o engine interpreta seus dados antes de gerar — mini-tabela aparece em tempo real nas textareas.
Export CSV · TSV · JSON
Exporte qualquer aba para CSV, copie como TSV para colar no Excel, ou baixe o JSON estruturado completo.
Detecção de duplicatas
Badge ⚠ aparece automaticamente se houver linhas idênticas. Clique para ver apenas as duplicatas.
Drag & Drop
Arraste arquivos .csv ou .txt diretamente para os campos de entrada.
Toggle de colunas
Esconda colunas irrelevantes nos resultados com um dropdown de checkboxes por aba.
Atalhos de teclado
⌘ Enter gera, ⌘ K busca, ⌘ D tema, ⌘ Z desfaz.
Modo escuro
Alterne pelo botão ou ⌘ D. Preferência salva automaticamente no navegador.
1

Engine de ParseEscolha o motor que interpreta seus dados

Clique no painel "Engine de Parse" no topo da ferramenta para expandi-lo. Você verá um grid com 12 engines disponíveis — cada um replica as convenções de uma linguagem de backend real.

ℹ️
Todos os engines rodam 100% no browser. Nenhuma chamada é feita a servidor. Cada engine apenas muda as regras: separador de coluna, palavras-chave de header e inferência de ambiente.
1
Abra o painel

Clique na barra "Engine de Parse" — ela se expande mostrando o grid de 12 linguagens. O painel lembra se estava aberto ou fechado.

2
Selecione o engine

Clique no card da linguagem desejada. O badge no topo ("JS JavaScript") se atualiza imediatamente. A parser strip abaixo mostra as regras ativas.

3
Leia as regras na parser strip

A faixa abaixo do painel descreve separador detectado, tipo de header e inferência de ambiente daquele engine. Use para formatar seus dados corretamente.

💡
Dica: se o seu backend é Python/Flask, selecione o engine Python. As regras de parse — incluindo word-boundary em DEV/SIT — serão idênticas ao que o servidor faria.
2

Massa de DadosComo formatar e inserir seus registros de teste

Cole seus dados no campo esquerdo. O engine detecta automaticamente o separador e o cabeçalho. Uma pré-visualização aparece imediatamente abaixo do campo enquanto você digita.

Formatos aceitos:

CSV — vírgula
CPF,Nome,Conta,Agência
123.456.789-00,João Silva,12345-6,0032
987.654.321-00,Maria Souza,98765-4,0001
CSV — ponto-e-vírgula (padrão Excel BR)
CPF;Nome;Conta;Agência
123.456.789-00;João Silva;12345-6;0032
987.654.321-00;Maria Souza;98765-4;0001
TSV — tab (colado direto do Excel)
CPF	Nome	Conta	Agência
123.456.789-00	João Silva	12345-6	0032
Sem cabeçalho — colunas inferidas automaticamente
123.456.789-00,João Silva,12345-6,0032
987.654.321-00,Maria Souza,98765-4,0001
🔖
Detecção de cabeçalho: se a primeira linha contiver palavras como cpf, nome, conta, agência, email, telefone etc., ela é tratada como cabeçalho. Caso contrário, colunas padrão são atribuídas (CPF, Nome, Conta, Agência).
3

DNS / AmbientesComo informar URLs e ambientes de teste

Cole as URLs no campo direito. Cada linha é uma entrada. Você pode prefixar com o nome do ambiente ou deixar o engine inferir pelo nome da URL.

Formato padrão — prefixo + espaço + URL
HML   app.hml.banco.com.br
PROD  app.prod.banco.com.br
DEV   api.dev.banco.com.br
SIT   api.sit.banco.com.br
UAT   api.uat.banco.com.br
Sem prefixo — ambiente inferido pelo nome da URL
app.hml.banco.com.br
app.prod.banco.com.br
api.dev.banco.com.br
⚠️
Engine TypeScript/Deno: linhas iniciadas com # ou // são tratadas como comentários e ignoradas. O ambiente HOM é usado no lugar de HML.
4

Gerar TabelasComo acionar o parse e interpretar os resultados

Com os dados preenchidos, clique em "Gerar Tabelas" ou pressione ⌘ Enter. Uma barra de estatísticas aparecerá seguida de três abas.

1
Clique em "Gerar Tabelas"

O engine processa os dois campos. Uma notificação toast confirma: "✓ N massas × M DNS = X combinações".

2
Verifique a Stats Bar

Mostra: registros de massa, entradas DNS, combinações geradas, ambientes distintos, colunas detectadas e engine ativo.

3
Navegue pelas três abas

Use Massas, DNS / Ambientes e Visão Combinada para explorar cada saída com filtro, ordenação e export independentes.

4
Use "Limpar" para recomeçar

O botão vermelho "Limpar" apaga tudo. Use ⌘ Z para desfazer caso tenha clicado por engano.

5

Filtrar e OrdenarBusca instantânea e ordenação por qualquer coluna

Cada aba possui um campo de busca independente. A filtragem é aplicada em todas as colunas simultaneamente, com debounce de 160 ms.

1
Filtrar por texto

Digite qualquer valor no campo "Filtrar…" — CPF, nome, URL, ambiente. Os termos ficam destacados em laranja. Pressione Esc para limpar.

2
Ordenar por coluna

Clique no cabeçalho de qualquer coluna para ordenar. Clique de novo para inverter (ASC → DESC). O ícone ↕ vira ↑ ou ↓ na coluna ativa.

3
Paginação e tamanho de página

Resultados paginados em grupos de 25 por padrão. Use o seletor "por página" (25/50/100/Tudo) e os botões ‹ › para navegar.

💡
Use ⌘ K para focar instantaneamente no campo de busca da aba ativa. Ideal para filtrar sem tirar as mãos do teclado.

Badges de AmbienteReferência de cores e palavras-chave reconhecidas

O engine detecta o ambiente pelo prefixo explícito (ex: HML url) ou infere pelo nome da URL. As palavras-chave abaixo são reconhecidas:

BadgePalavras-chave na URLExemplo
HMLhml, homologapp.hml.banco.com.br
PRODprod, prdapp.prod.banco.com.br
DEVdevapi.dev.banco.com.br
SITsitapi.sit.banco.com.br
UATuatapi.uat.banco.com.br
QASqas, qaapi.qas.banco.com.br
—Nenhuma correspondênciaURL sem palavras-chave conhecidas
🔖
Engines especiais: Swift usa PRD como fallback (não PROD). TypeScript/Deno usa HOM para homologação. Kotlin detecta STG (staging). Java prioriza PROD antes de HML.

Os 12 EnginesDiferenças e comportamentos específicos de cada linguagem

Cada engine replica as convenções da linguagem correspondente. As diferenças principais:

JS
🟨 JavaScript
Node.js · Express
Engine padrão. Separador: tab › ; › ,. inferEnv usa includes().
PY
🐍 Python
Flask 3 · Gunicorn
Usa regex com word-boundary (\bdev\b). Rows curtos recebem padding "".
JAVA
☕ Java
Spring Boot 3.2
Infere PROD antes de HML. Headers em HashSet.
GO
🐹 Go
net/http · stdlib
Sem cabeçalho → colunas Col1, Col2…ColN (não CPF/Nome). Env vazio = "".
PHP
🐘 PHP
Built-in server
Usa str_contains(). Env padrão: OTHER (não UNKNOWN).
RB
💎 Ruby
Sinatra 3
Separador com include?. Produto com blocos .each { |r| }.
RS
🦀 Rust
Actix-web 4
Rows em Vec<String> com padding "". Usa str::contains().
C#
🔷 C#
.NET 8 Minimal API
Headers em HashSet<string>. Usa IsNullOrWhiteSpace().
KT
🎯 Kotlin
Ktor 2.3
DNS aceita url ENV (env no final). Detecta STG.
SW
🦅 Swift
Vapor 4
Separador pelo mais frequente (contagem). Fallback: PRD.
TS
🦕 TypeScript
Deno · Oak 12
Ignora # e //. Usa HOM no lugar de HML.
R
📊 R
Plumber 1.2
Usa grepl() com ignore.case=TRUE. Produto com loop aninhado.

Drag & DropCarregue arquivos arrastando diretamente para os campos

Em vez de copiar e colar, você pode arrastar arquivos direto para os cards de entrada. Funciona com qualquer arquivo de texto.

1
Arraste o arquivo para o card

Arraste um arquivo .csv ou .txt da sua área de trabalho para cima do card "Massa de Dados" ou "DNS / Ambientes".

2
Veja o feedback visual e solte

O card ficará com borda laranja e elevado enquanto você segura o arquivo. Ao soltar, o conteúdo é carregado, o contador de linhas se atualiza e a pré-visualização aparece.

3
Gere normalmente

Com o arquivo carregado, clique em "Gerar Tabelas" ou pressione ⌘ Enter.

💡
Encoding: o arquivo é lido como UTF-8. Certifique-se de que seu CSV está salvo nesse encoding para evitar problemas com acentos (ã, ç, é…). Arquivos exportados do Excel muitas vezes usam Latin-1 — salve como UTF-8 antes.

Perguntas FrequentesDúvidas comuns sobre a ferramenta

O que significa "produto cartesiano" na Visão Combinada?▼
Cada registro de massa é combinado com cada URL de DNS. Com 3 registros e 4 URLs, a Visão Combinada terá 3 × 4 = 12 linhas. É ideal para mapear todos os cenários de teste de uma vez, eliminando a necessidade de copiar e colar manualmente.
Qual engine devo escolher para o meu time?▼
Escolha o engine que corresponde ao backend que vai consumir os dados. Se o backend é Python/Flask, use Python. Se é Node.js/Express, use JavaScript. Isso garante que as regras de parse — separador, detecção de cabeçalho, inferência de ambiente — sejam idênticas ao que o servidor faria.
Meus dados ficam armazenados em algum servidor?▼
Não. A ferramenta roda 100% no browser. Nenhum dado é enviado para servidor. Tudo é processado em JavaScript no seu computador. Você pode usar dados sensíveis (CPFs, senhas de teste) sem preocupação com vazamento externo.
Como copiar os resultados para o Excel?▼
Use o botão TSV em qualquer aba — ele copia a tabela formatada com tabs para a área de transferência. Abra o Excel (ou Google Sheets) e cole com Ctrl+V. As colunas serão automaticamente separadas. Alternativa: use CSV para baixar um arquivo e importar via "Dados → Importar".
O que acontece se minha massa não tiver cabeçalho?▼
Se a primeira linha não contiver palavras conhecidas (cpf, nome, conta etc.), o engine atribui colunas padrão: CPF, Nome, Conta, Agência. Colunas extras recebem Col5, Col6…. O engine Go usa Col1, Col2… como padrão em vez de CPF/Nome.
Posso detectar linhas duplicadas na minha massa?▼
Sim! Após gerar, a aba Massas exibe automaticamente um badge ⚠ N dups caso haja linhas idênticas. Clique no badge para filtrar apenas as duplicatas. Linhas duplicadas ficam com fundo avermelhado e um indicador 2× na primeira coluna. Atalho: ⌘⇧D.
Como usar no Windows ou Linux?▼
Use Ctrl no lugar de ⌘: Ctrl+Enter para gerar, Ctrl+K para busca, Ctrl+D para tema, Ctrl+Z para desfazer. Todo o resto funciona identicamente em qualquer sistema operacional.
